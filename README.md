# setlist-creator
Create setlists with custom notes

# features
- CRUD for songs with title, key and sound
- CRUD for setlists with ordering
- song search on songs and setlist page
- persistent storage/database with supabase
- deployment through vercel
- easy authentication with password in environment variables
- page for songs and page for setlists
- PWA with versimpelde weergave for playing setlists

# known issues
- manual copy-paste songs from google docs
- edit song order on mobile not user friendly
